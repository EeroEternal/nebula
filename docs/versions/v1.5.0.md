# Nebula v1.5.0

发布日期：2026-08-11。

完整变更见根目录 [`CHANGELOG.md`](../../CHANGELOG.md)。

## 一句话

对外集成面 **v1 就绪**：Gateway `/platform/v1/*` 控制 API（Operation、API Key、SSE、幂等、治理只读）；legacy `/v1/admin/*` 标记下线日期。

## 主要变化

| 项 | 说明 |
|----|------|
| Control API | `/platform/v1/models`、`…/deployment`、`…/operations`、`…/health/summary` 等；见 [`docs/dev/integration.md`](../dev/integration.md) |
| 鉴权 | Postgres API Key（`control` / `inference` / `admin` scope）；兼容 `NEBULA_AUTH_TOKENS` |
| 异步 | 写操作 202 + `operation_id`；SSE 或轮询直到 `succeeded` |
| 治理读 | SLO / Canary 只读 API（写仍走控制台 BFF） |
| Legacy | `/v1/admin/*` 响应含 `Sunset: 2027-02-11`；计划 v1.6.0 移除 |

## 升级注意

- 新集成请只用 `/platform/v1/*`；勿再依赖 `/v1/admin/v2/*` BFF 代理。
- 需 BFF Postgres 时 API Key 鉴权才可用；纯 env token 仍可用于开发。
- 契约：[`docs/dev/openapi-control.yaml`](../dev/openapi-control.yaml)、[`docs/dev/integration-plan.md`](../dev/integration-plan.md)。

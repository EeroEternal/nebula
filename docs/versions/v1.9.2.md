# Nebula v1.9.2

发布日期：2026-09-20。

完整变更见根目录 [`CHANGELOG.md`](../../CHANGELOG.md)。

## 一句话

**补丁版**：把 console-kit 的前端 lint 规则（token 与受限语法）落到 `frontend/`，并把本地 CI 门禁收敛为单个 `./scripts/ci.sh`（等价于已删除的 GitHub Actions workflow）。无运行时行为变更。

## 主要变化

| 模块 | 变更说明 |
|------|----------|
| **前端 lint 规则** | `frontend/eslint.config.js` 启用 console-kit 规则：禁止硬编码 hex、禁止调色板色阶类（`bg/text/border-{gray,zinc,slate,red,…}-NN`）、禁止原生 `<select>` / `<dialog>` / `window.alert|confirm|prompt`。剩余 6 处原生 `<select>` 迁移为共享 `Select` 组件（LoadModelDialog、account-settings、governance、images ×2、model-catalog）。 |
| **本地 CI 门禁** | `./scripts/ci.sh` 现为全量门禁：`cargo fmt --check` → `clippy --all-targets -- -D warnings` → `cargo test --workspace --all-targets` → OpenAPI 契约检查 → UI 栈/导航检查 → 前端 `tsc + eslint + build`。`RUN_SMOKE=1` 仍为可选冒烟。`pre-push-local-gates` 技能清单同步更新。 |

## 升级注意

- 无接口、schema 或运行时行为变化；`v1.9.1 → v1.9.2` 可直接覆盖升级。
- 本版仅为 patch：没有新增模型/路由能力，也没有破坏性变更。

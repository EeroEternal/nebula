# Nebula v1.7.0

发布日期：2026-08-29。

完整变更见根目录 [`CHANGELOG.md`](../../CHANGELOG.md)。

## 一句话

**架构清晰化**：下线单机 Lite 方案；BFF 业务资产与历史数据全量迁入 PostgreSQL，etcd 严格聚焦声明式排班协调。

## 主要变化

| 模块 | 变更说明 |
|------|----------|
| **下线单机** | 移除 `crates/nebula-lite`，专注分布式集群跨引擎控制面。 |
| **存储分层** | 模板（`bff_templates`）、模型画像（`bff_model_profiles`）、租户定价（`bff_pricing`）、用量流水（`bff_usage`）及基准评测（`bff_benchmark_runs` / `bff_benchmark_profiles`）全量迁入 PostgreSQL。 |
| **etcd 瘦身** | etcd 彻底移除非协调类借住数据，体量恒定轻量，保障毫秒级调度与事件分发。 |
| **CI 与工程** | 清理旧工作流与无用模板，优化 CI 流水线。 |

## 升级注意

- BFF 依赖的 PostgreSQL 表在服务启动时通过 `initialize_auth_schema` 自动建表与升级。
- 节点（Node）、网关（Gateway）与路由器（Router）无需连接 PostgreSQL，推理热路径行为保持不变。

# Nebula v1.9.1

发布日期：2026-09-20。

完整变更见根目录 [`CHANGELOG.md`](../../CHANGELOG.md)。

## 一句话

**补丁版**：统一文档中「核心无兼容层」的边界表述（对齐 v1.9.0 已交付的 PowerLLM 控制台兼容层），并修掉 `admin/` 在嵌套检出下的安装脚本问题。无运行时行为变更。

## 主要变化

| 模块 | 变更说明 |
|------|----------|
| **文档边界澄清** | `dev/integration.md`、`arch/control-plane-adapters.md`、`arch/vision.md`、`arch/architecture.md` 统一措辞：热路径（Gateway `:8081` / Router）与 etcd 控制面保持平台无关、零平台分支；BFF（`:18090`）的 PowerLLM 控制台兼容层是**控制台边缘南向适配**，既非 `CONTROL_PLANE` 适配器也不入热路径。 |
| **Admin 安装脚本** | `admin/package.json` 的 `prepare` 改为 `test -d ../.git && husky install \|\| true`，`admin/` 作为 vendored 拷贝、无外层 git 仓库时 `npm install` 不再失败。 |

## 升级注意

- 无接口、schema 或运行时行为变化；`v1.9.0 → v1.9.1` 可直接覆盖升级。
- 本版仅为 patch：没有新增模型/路由能力，也没有破坏性变更。

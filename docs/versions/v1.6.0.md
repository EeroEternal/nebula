# Nebula v1.6.0

发布日期：2026-08-11。

完整变更见根目录 [`CHANGELOG.md`](../../CHANGELOG.md)。

## 一句话

**移除** Gateway legacy `/v1/admin/*`；控制面仅 **`/platform/v1/*`**。

## 主要变化

| 项 | 说明 |
|----|------|
| 移除 | `/v1/admin/models/load`、`…/cluster/status`、镜像 CRUD、Gateway 日志、BFF v2 代理等 |
| 迁移 | `GET /platform/v1/cluster/status`、`/whoami`、`POST /replicas/drain` |
| CLI | 控制走 Platform v1；模板/缓存等 v2 直连 BFF `:18090/api/v2` |

## 升级注意

- 所有 `/v1/admin/*` 调用须改为 `/platform/v1/*`（见 [`docs/dev/integration.md`](../dev/integration.md)）。
- `nebula-cli` 新增 `--bff-url` / `NEBULA_BFF_URL`（默认 `:18090`）。
- 镜像注册、Gateway 本地日志等仅保留在控制台 BFF，不再经 Gateway Admin 暴露。

# Nebula v1.8.0

发布日期：2026-08-29。

完整变更见根目录 [`CHANGELOG.md`](../../CHANGELOG.md)。

## 一句话

**L2 资源池化与优雅运维**：引入 `HardwarePool` 算力池资源隔离与调度硬约束；支持一键整机优雅排空（Node Drain）。

## 主要变化

| 模块 | 变更说明 |
|------|----------|
| **算力池化 (`HardwarePool`)** | 新增 `HardwarePool` 契约；支持平台、角色、节点列表与可调度（`schedulable`）状态管控。 |
| **池调度硬约束** | `ModelDeployment` 新增 `allowed_pools` 字段；调度器严格进行池内节点筛选，杜绝跨池故障蔓延。 |
| **整机优雅排空 (`Node Drain`)** | 支持 `POST /platform/v1/nodes/:node_id/drain` 及 `POST /api/v2/nodes/:node_id/drain`，一键将物理机上所有模型副本置为 `Draining`，配合 Router 零丢请求优雅下线。 |
| **CLI 支持** | `nebula-cli` 新增 `nebula pool [list|get|create|delete]` 与 `nebula drain --node-id <node_id>` 命令行。 |

## 升级注意

- `HardwarePool` 属于控制面集群配置，存储在 etcd `/pools/{pool_id}`。
- `ModelDeployment.allowed_pools` 缺省为空，保持完全向后兼容（在全集群健康节点内调度）。

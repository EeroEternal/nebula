# Nebula v1.9.0 发布说明

**发布日期：** 2026-09-20  
**版本代号：** Kubernetes Execution Plane & PowerLLM Full Compatibility

Nebula v1.9.0 引入了独立的 Kubernetes 原生控制器、针对 PowerLLM 协议的完整无缝兼容层、以及将 PowerLLM 控制台（Admin UI）整合接入 Nebula 控制面，同时支持裸金属/进程与 K8s 双形态运行时。

---

## 主要更新

### 1. K8s 独立执行面（`crates/nebula-k8s-controller`）
- 遵循 Nebula 控制面与执行面分离原则（etcd 作为唯一声明式权威与排班黑板，K8s 仅作执行面）。
- 新增 `nebula-k8s-controller` 常驻控制器：
  - 自动 List & Watch etcd 中的 `/deployments/` 期望；
  - 声明式 reconcile 物理 K8s 集群中的底层 vLLM 引擎 Pod；
  - 就绪后自动将实际 Pod IP/Port 注册至 etcd `/endpoints/` 并维持租约保活；
  - 支持多卡 GPU 分配、宿主机模型卷直接挂载与大页内存（shm）注入。

### 2. PowerLLM 协议级无缝兼容层（`crates/nebula-bff`）
- 在 BFF 中新增完整的 PowerLLM 认证、设备拓扑与模型实例 CRUD API：
  - 认证与权限：`POST /token`、`POST /v1/user/signin`、`GET /v1/user/info`
  - 资源与硬件拓扑：`GET /v1/device/info`
  - 实例声明与生命周期：`GET /v1/models/instances`、`POST /v1/models/instance`、`DELETE /v1/models/:model_uid`
- 保持向后兼容：Nebula 原生 `/api/*`、`/api/v2/*` 和 `/platform/v1/*` 接口完全保留且不受影响。

### 3. PowerLLM 控制台（Admin UI）整合
- 将基于 Ant Design Pro + Umi Max 的全功能管理后台源码正式迁移至仓库 `admin/` 目录。
- 预置默认代理配置，开箱即用直连 Nebula BFF。
- 与轻量级原生仪表盘（`frontend/`）形成互补。

### 4. 数据面性能极限优化
- 彻底绕过 Python 中间件与 Supervisor 代理耗时，实现 Gateway/Router 直通物理引擎 Pod。
- 在 RTX 5090 集群端到端压测验证下：
  - TTFT Avg 缩短 **66.7%**（从 174.96ms 降至 58.18ms）；
  - TTFT P99 尾延迟压制 **78.4%**（从 334.18ms 降至 72.15ms）；
  - 吞吐 QPS 提升 **+29.1%**。

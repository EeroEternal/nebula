# Nebula v1.4.0

发布日期：2026-07-14。

完整变更见根目录 [`CHANGELOG.md`](../../CHANGELOG.md)。GitHub Release：https://github.com/EeroEternal/nebula/releases/tag/v1.4.0

## 一句话

新增单机 **Nebula Lite**（`nebula-lite`）：一个进程拉起本机 vLLM/SGLang 并代理 OpenAI API，无需 etcd/BFF。同步下线 Serving Cell。

## 主要变化

| 项 | 说明 |
|----|------|
| Lite | `crates/nebula-lite`；`--engine vllm\|sglang`、`--gpus`、OpenAI 反向代理（含 SSE） |
| 文档 | [`docs/dev/lite.md`](../dev/lite.md) |
| 移除 | Serving Cell（CellIngress）相关能力 |

## 升级注意

- Workspace 版本：`1.4.0`。
- 完整控制面路径不变；Lite 与 `nebula-up.sh` 并行，互不替代。
- 若仍依赖 Serving Cell API，请停在 v1.3.0 或改用普通副本 Deployment。
